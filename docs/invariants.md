# Evidence-pack invariants

This repository is historical evidence. Its rules are about truthfulness and sanitization.

1. **Historical code is labelled historical.**
2. **No file claims this is the current telephony runtime.**
3. **Credentials, customer data, patient data, and live identifiers stay out.**
4. **Every published artifact has a stated evidentiary purpose.**
5. **Provider migration context stays visible instead of being edited out to make the story cleaner.**
6. **A public extract may demonstrate implementation history; it does not prove current deployment state.**

The point is not to make old code look new. The point is to make real work reviewable without leaking the private system.
