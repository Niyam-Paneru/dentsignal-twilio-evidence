# Sanitization and security

This repository is historical evidence, not a live telephony deployment.

The public extracts intentionally exclude credentials, customer/clinic records, patient data, live phone numbers, environment identifiers, private webhooks, and unrelated product code.

Do not treat old setup notes as current provider guidance. Re-verify webhook security, authentication, provider configuration, data-handling rules, and legal/compliance requirements before using similar code in a real system.
